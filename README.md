# DeepLearning-GenAI

Welcome to the **DeepLearning-GenAI** repository! This is a repository dedicated to implementing various deep learning and generative AI projects. The aim is to explore cutting-edge algorithms and create solutions for a range of problems using the latest advancements in artificial intelligence and machine learning.

## Current Project: Text Summarization

### Overview
In this section, I am focusing on **Text Summarization** — a subdomain of NLP (Natural Language Processing) that involves condensing long text into shorter summaries while preserving important content and context.

The goal is to implement various text summarization techniques:
- **Extractive Summarization** – Selecting key sentences directly from the source text.
- **Abstractive Summarization** – Generating concise summaries using deep learning models.
